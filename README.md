# Algorithms & Data Structures

> My Python solutions to data-structures and algorithms problems, organized by category and difficulty. A personal practice repository for sharpening problem-solving — every solution written from scratch in my own approach.

---

## About

This repo is where I work through data-structures and algorithms problems. Solutions are grouped first by **topic** (arrays, trees, recursion) and then by **difficulty**, so the progression from approachable warm-ups to genuinely hard problems is easy to follow. Most of the categorized problems come from **[AlgoExpert](https://www.algoexpert.io/)**; the `Random` folder holds assorted exercises and classic programming puzzles I've tackled along the way.

The solutions are my own implementations — worked out independently rather than copied — so they reflect how I actually reason through each problem.

## Running a solution

Each file is a standalone Python script or class. Run any of them with Python 3:

```bash
python3 "Arrays/Medium/LongestPeak.py"
```

Requires Python 3.
